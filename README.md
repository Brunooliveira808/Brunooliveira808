## 👨‍💻 Sobre mim

Estudante de **Ciência da Computação** (Estácio) e desenvolvedor **Back-End Java**, focado em construir **APIs REST seguras, testadas e bem estruturadas** com o ecossistema Spring.

Gosto de levar projetos além do básico: começo com o essencial e vou evoluindo com novas tecnologias — autenticação com **JWT**, testes com **JUnit/Mockito**, containers com **Docker** e documentação com **Swagger**.

- 🎯 **Objetivo:** Estágio em Software Engineering / Back-End
- 🔐 **Foco atual:** Spring Security, JWT, AWS boas práticas de arquitetura
- 🤖 **Explorando:** Integração de APIs com LLMs e Inteligência Artificial
- 📍 Araraquara - SP · 🇺🇸 Inglês intermediário
